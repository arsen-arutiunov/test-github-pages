# test-github-pages

Небольшой статический сайт на GitHub Pages: https://arsen-arutiunov.github.io/test-github-pages/

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | Главная страница (каталог разделов) |
| `floor-is-lava.html` | Игра «THE FLOOR IS LAVA — Present Simple Challenge» (раньше была в `index.html`) |
| `vocabulary.html`, `grammar.html` | Страницы-заглушки для будущих разделов |
| `menu.html` | **Единственный** файл с разметкой меню (можно открыть и как обычную страницу) |
| `assets/menu.js` | Загружает меню из `menu.html` на каждую страницу и подсвечивает текущий пункт |
| `assets/site.css` | Общие стили (все классы начинаются с `site-`, чтобы не мешать игре) |

Если меню загрузить не получилось (нет сети, JavaScript выключен, страница открыта как файл), на странице остаются запасные ссылки «Главная» и «Все разделы» (`menu.html`).

## Как добавить новую страницу

1. Скопируйте `vocabulary.html` под новым именем, например `reading.html`, и поменяйте `<title>` и текст.
2. Добавьте пункт в `menu.html`:
   ```html
   <li><a class="site-nav__link" href="reading.html">Чтение</a></li>
   ```
3. По желанию добавьте карточку на главную (`index.html`).

Используйте только относительные ссылки (`reading.html`, а не `/reading.html`), иначе они не будут работать по адресу `/test-github-pages/`.

## Как посмотреть локально

Меню загружается через `fetch`, поэтому откройте сайт через локальный сервер, а не двойным кликом по файлу:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000/.
